  3. Get a certificate for your agent

    Each agent proves who it is with its own client certificate. Its name (the certificate's CommonName) is how Conduit labels everything the agent sends. For security, certificates and keys are made on the command line and never shown or served by this UI.

    Using the quickstart
    It already made one for my-agent, in deployments/quickstart/.conduit/certs.
    Another agent name, or your own stack
    ./scripts/gen-certs.sh agent research-bot
    Writes certs/research-bot.crt and .key, signed by certs/ca.crt. In production, issue it from your own PKI.

  4. Send your first trace

    Point the SDK at the certificates, then run an example or your own code:

    export CONDUIT_GATEWAY_ADDR={{.GatewayAddr}}
export CONDUIT_CERT_DIR=$PWD/deployments/quickstart/.conduit/certs
export CONDUIT_AGENT=my-agent
    Python 
    pip install -e sdk/python
python examples/python/hello_trace.py

    In your own code:

    import conduit_observability as conduit

conduit.configure()                 # reads the CONDUIT_* variables

@conduit.traced()
def run_agent(task): ...
    Go 
    cd examples/go && go run ./hello-trace

    In your own code:

    client, err := sdk.NewFromEnv()     // reads the CONDUIT_* variables
span, ctx := client.StartSpan(ctx, "agent.run")
defer span.End(ctx)
    More examples

    Tool calling, asyncio, Claude and OpenAI agents, in examples/. See the examples guide.
